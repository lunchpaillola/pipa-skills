# Improve Operations Examples

## Lessons Capture

- `Lesson`: kickoff needed a named decision owner before delivery started
- `Evidence`: two blocked scope decisions in delivery notes
- `Next-time change`: add decision owner to define-work acceptance checks
- `Owner`: TBD
- `Reuse location`: project playbook or `TBD`
- `Follow-ups`: confirm handover/archive readiness

## Closure Request

Do not declare closure unless signoff, handover, and archive evidence are present or the user explicitly accepts the gap.

## Daily Shutdown

- `Baseline`: accepted Daily Plan available, or `baseline unavailable`
- `Plan versus actual`: each commitment is completed, partial, blocked, deferred, dropped, or unknown
- `Open loops`: every item has an explicit disposition
- `Tomorrow seed`: first likely priority plus constraints and source gaps
- `Source coverage`: tracker used, code host failed, calendar used; code-dependent outcomes stay unknown
- `Closure`: ritual complete, open work carried; no messages or events created without separate approval
