# Daily Plan Output

```md
# Daily Brief - <weekday, date>

## Your Day
<Short summary of the calendar and what the day calls for.>

## Main Focus
**<ticket or outcome>** - <why this is the best choice>
- Done looks like: <clear outcome>

## If Time Allows
1. <secondary item>
2. <optional second item>

## Schedule
- <time>: <event or work block>

I pulled this from: <apps, linked records, and user context used>.
```

Omit empty sections. Use natural prose. Do not show todo progress, connector status, backlog totals, or long source-gap lists unless the user asks for diagnostics.
